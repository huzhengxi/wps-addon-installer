# 添加自定义控件源

控件源是一个通过 HTTPS 访问的 JSON 索引地址，不是本地文件夹，也不是任意网页。

1. 打开“控件源”，点击“添加控件源”。
2. 填写易于识别的名称和 `https://` 开头的索引 URL。
3. 保存后先点击“测试连接”。
4. 只有测试通过后再启用该源。

请只添加可信来源。安装器会校验索引格式、HTTPS 和每个插件包的 SHA-256；即便源可访问，校验不通过的插件也不会被安装。

默认建议使用 GitHub Pages 托管索引、GitHub Releases 托管版本化插件包。国内镜像可使用 Gitee Releases；下载量提高后可使用 Cloudflare R2 绑定自有域名。
