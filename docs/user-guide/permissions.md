# 恢复 WPS 目录访问权限

## macOS

1. 在“权限”页面点击“重新申请权限”。
2. 如果系统没有弹出授权窗口，打开“系统设置 → 隐私与安全性 → 文件与文件夹”，允许 WPS 插件管理器访问所需目录。
3. 仍然无法写入时，在“完全磁盘访问权限”中添加 WPS 插件管理器，然后重新打开应用并点击“重新检测”。

## Windows

1. 在“权限”页面点击“重新申请权限”。
2. 检查“设置 → 隐私和安全性 → 文件系统”是否允许应用访问文件系统。
3. 如果 Windows 安全中心的“受控文件夹访问”拦截了应用，请在该功能中将 WPS 插件管理器加入允许列表。
4. 只有界面明确提示需要提升权限时，才以管理员身份重新打开应用。

授权恢复后，安装器会重新检测状态，但不会未经确认自动继续安装或卸载。
